# business-agent-lab

## what I want to build with agents

**너의 별자리는?** — 대학생이 자신의 경험을 기록하고, 경험과 태그가 이어진 별자리(Experience Graph)를 보며
"내가 무엇을 해 왔는지, 나는 어떤 사람인지, 앞으로 무엇을 채워야 하는지"를 스스로 발견하는 서비스 프로토타입.

- 앱: [`byeoljari/index.html`](byeoljari/index.html) — 파일 하나로 동작하는 웹 앱. 브라우저에서 바로 열면 됩니다.
- 기반 문서: 비즈니스에이전트설계 중간 기획서

### 주요 기능 (MVP)

| 화면 | 내용 |
|---|---|
| 별자리 | 경험·태그·전공 분야·관측 예정 별을 잇는 밤하늘 그래프. 별 색 = 활동 유형(8색), 크기·밝기 = 중요도 + 성장 영향 |
| 기록 | 자유 형식 기록, 가이드 질문, 사진·파일 첨부, 0.5 단위 별점 2종, 태그 추천 |
| 능력치 | 성장 별점 합으로 계산한 역량·분야별 레이더 차트, 막대 색 = 성장이 나온 활동 유형 |
| 타임라인 | 상위 태그 누적 곡선(마우스를 올리면 월별 값), 경험 별 줄, 학기별 카드 |
| 목표 | 목표·필요 영역 직접 입력 → 충분 / 쌓는 중 / 필요, 관측 예정 별 추가 |
| 요약 | 활동 요약과 규칙 기반 분석 코멘트 (경험 3개 이상) |
| 내 정보 | 전공 분야 설정·나누기, 태그-분야 연결 수정, 백업, 튜토리얼 |

### 구현 메모

- AI 기능(태그 추천, 기록 가이드 질문, 분석 코멘트)은 외부 API 없이 키워드 사전과 규칙으로 동작합니다.
- 데이터는 각 사용자의 브라우저 `localStorage`에만 저장됩니다. 백업은 JSON 내보내기·불러오기로 합니다.
- 그래프는 d3 7.8.5 (cdnjs)를 사용합니다.
- 첫 방문 시 예시 학생 데이터로 튜토리얼을 보여 주고, 끝나면 빈 상태로 시작합니다.
